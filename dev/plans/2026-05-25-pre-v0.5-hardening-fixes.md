### Task 1.1: Parser drops run records when a JSON value embeds a code fence

**Problem:** `_extract_json_blocks` (`src/urika/orchestrator/parsing.py:25`) uses `re.compile(r"```(?:json|JSON)\s*(.*?)```", re.DOTALL)`. The non-greedy `(.*?)` stops at the FIRST ```` ``` ````. When a task-agent record embeds a ```` ```python ```` snippet inside an `observation`/`hypothesis` string, capture truncates mid-JSON, `json.loads` fails, the block is dropped. Downstream (`loop.py:950`) an experiment can then record 0 runs and be marked `failed` despite real work. Same truncation defeats `parse_evaluation` (criteria never registered met).

**Fix approach:** After locating each ```` ```json ```` opening fence, do **brace-balanced** extraction of the JSON object/array (respecting string literals and escapes) instead of regex-matching to the next ```` ``` ````. Fall back to the old behaviour only if balancing fails.

**Files:**
- Modify: `src/urika/orchestrator/parsing.py:15-50`

```python
def _find_balanced_json(text: str, start: int) -> tuple[str, int] | None:
    """From ``text[start:]`` (first non-space char must be { or [),
    return (json_substring, end_index) covering the balanced object/array,
    honoring string literals and escapes. None if unbalanced."""
    i = start
    n = len(text)
    while i < n and text[i] in " \t\r\n":
        i += 1
    if i >= n or text[i] not in "{[":
        return None
    open_ch = text[i]
    close_ch = "}" if open_ch == "{" else "]"
    depth = 0
    in_str = False
    escape = False
    j = i
    while j < n:
        c = text[j]
        if in_str:
            if escape:
                escape = False
            elif c == "\\":
                escape = True
            elif c == '"':
                in_str = False
        else:
            if c == '"':
                in_str = True
            elif c == open_ch:
                depth += 1
            elif c == close_ch:
                depth -= 1
                if depth == 0:
                    return text[i : j + 1], j + 1
        j += 1
    return None


def _extract_json_blocks(text: str) -> list[dict[str, Any]]:
    """Find all ```json fenced blocks, parse them, skip malformed.

    Uses brace-balanced extraction from the opening fence so a code
    fence embedded inside a JSON *string value* (e.g. a Python snippet
    in an ``observation`` field) no longer truncates the match. Falls
    back to the legacy non-greedy regex slice only if balancing fails.
    """
    results: list[dict[str, Any]] = []
    open_re = re.compile(r"```(?:json|JSON)[ \t]*\r?\n?", re.IGNORECASE)
    for m in open_re.finditer(text):
        balanced = _find_balanced_json(text, m.end())
        if balanced is not None:
            raw = balanced[0]
        else:
            # Legacy fallback: slice to the next closing fence.
            tail = text[m.end():]
            close = tail.find("```")
            raw = (tail[:close] if close != -1 else tail).strip()
        try:
            parsed = json.loads(raw)
        except (json.JSONDecodeError, ValueError) as exc:
            preview = raw[:120].replace("\n", "\\n")
            logger.warning(
                "Skipping malformed JSON block in agent output: %s: %s; raw[:120]=%r",
                type(exc).__name__,
                exc,
                preview,
            )
            continue
        if isinstance(parsed, dict):
            results.append(parsed)
    return results
```

    from starlette.middleware.base import BaseHTTPMiddleware
    from starlette.responses import JSONResponse

    SAFE_METHODS = {"GET", "HEAD", "OPTIONS"}

    class _OriginGuard(BaseHTTPMiddleware):
        async def dispatch(self, request, call_next):
            if request.method not in SAFE_METHODS:
                origin = request.headers.get("origin")
                if origin is not None:
                    host = request.headers.get("host", "")
                    # Allow only same-host origins (scheme-agnostic).
                    from urllib.parse import urlparse
                    if urlparse(origin).netloc != host:
                        return JSONResponse(
                            {"detail": "cross-origin request rejected"},
                            status_code=403,
                        )
            return await call_next(request)

    app.add_middleware(_OriginGuard)
```

(Requests with no `Origin` header — e.g. curl, server-side — are allowed; browsers always send `Origin` on cross-origin state-changing requests, which is the threat being closed.)

```python
"""Block SSRF to private/loopback/link-local/reserved addresses."""
from __future__ import annotations

import ipaddress
import socket
from urllib.parse import urlparse


class BlockedHostError(ValueError):
    """Raised when a URL resolves to a non-public address."""


def _is_blocked_ip(ip: ipaddress._BaseAddress) -> bool:
    return (
        ip.is_private
        or ip.is_loopback
        or ip.is_link_local
        or ip.is_reserved
        or ip.is_multicast
        or ip.is_unspecified
    )


def assert_public_host(url: str) -> None:
    """Raise BlockedHostError if the URL's host resolves to a non-public IP.

    Resolves ALL A/AAAA records and blocks if ANY is non-public (defeats
    DNS-rebind-to-localhost). Callers that legitimately need private
    endpoints (the privacy preflight for user-declared private LLMs)
    must opt out explicitly rather than calling this."""
    host = urlparse(url).hostname
    if not host:
        raise BlockedHostError("URL has no host")
    try:
        infos = socket.getaddrinfo(host, None)
    except socket.gaierror as exc:
        raise BlockedHostError(f"cannot resolve host: {exc}") from exc
    for info in infos:
        addr = info[4][0]
        try:
            ip = ipaddress.ip_address(addr.split("%")[0])
        except ValueError:
            continue
        if _is_blocked_ip(ip):
            raise BlockedHostError(f"host resolves to non-public address {ip}")
```

### Task 3.2: `acquire_lock` empty-lock branch can clobber a live lock (TOCTOU)

**Problem:** `src/urika/core/session.py:157-178`.     # itself the exclusivity check, closing the empty-lock TOCTOU where
    # a concurrent acquirer could read a half-written empty file and
    # treat the live lock as stale.
